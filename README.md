# Jewelry By Nadia — GitHub-ready frontend

Responsive React/Vite jewelry storefront prepared from the approved Jewelry By Nadia desktop/mobile references.

## What is included

- Approved desktop hero bitmap
- Dedicated valid mobile hero bitmap derived from the approved hero source
- 13 optimized jewelry catalog images with deterministic filenames
- Responsive Shop By Category grid
- Responsive Signature Collection product grid
- Emerald / Bridal / Private Styling feature cards
- Shop By Occasion cards
- Crafted To Perfection panel
- Newsletter and compact luxury footer
- Mobile-first layout tuned for 375px, 390px, 430px and larger breakpoints

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vite writes the production bundle to `dist/`.

## GitHub / AI Studio import

Upload the contents of this folder to the repository root. Do not upload an extra parent folder around the project. Then import the repository into Google AI Studio. The app needs no environment variables or backend service for the current frontend demo.
